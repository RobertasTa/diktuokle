Diktuoklė

Голосовая диктовка без интернета для Windows — по-русски, по-литовски, по-английски.

Держите Ctrl, говорите — текст появляется. На вашем компьютере, бесплатно.

Скачать для Windows Код на GitHub

Подробная инструкция (на английском): README_EN.md

Что это

В любой программе

Word, браузер, переписка, бухгалтерская программа — текст появляется там, где мигает курсор. Держите правый Ctrl и говорите, отпустили — записано.

Работает без интернета

Распознавание речи идёт на вашем компьютере. Звук и текст никогда его не покидают. Ни аккаунтов, ни абонентской платы, ни фильтра нецензурных слов.

Русский — GigaAM

С версии 0.2 русскую речь распознаёт GigaAM v3 (SberDevices): около 0,1 с на предложение прямо на процессоре — раньше Whisper large-v3 без видеокарты думал около 7 с. Загрузить нужно всего 0,23 ГБ.

Литовский — LT_ausys

Литовскую речь распознаёт LT_ausys — модель «kmynas» Кристиёнаса Якубсонаса, обученная на ~3 087 часах литовской речи. Ошибок в словах заметно меньше, чем у прежней Paprika: 17,9 % против 22,8 % на командах автора.

Знаки препинания сами

Запятые, кавычки и заглавные буквы модель расставляет сама. В режиме «123» числа словами превращаются в цифры: «Двадцать пять рублей, а не тридцать» → «25 рублей, а не 30».

Быстро без видеокарты

Русский и литовский работают на процессоре: команда — за 0,05–0,2 с, минута диктовки — за несколько секунд. Видеокарта ускоряет только английский. Держа Ctrl, нажмите → — и говорите на другом языке, не отпуская клавишу.

Как это выглядит

На снимках интерфейс литовский. Язык интерфейса — первый отмеченный в установщике (порядок там: литовский, русский, английский). Выберете русский без литовского — вся программа будет по-русски; сам установщик тоже есть на русском.

Чего ждать в первый раз

Установщик маленький (~90 МБ). Модели загружаются при первом запуске и только для выбранных языков:

ВыбраноЗагрузит
только русский~0,23 ГБ
только литовский~1 ГБ
только английский~3,1 ГБ
русский + литовский~1,2 ГБ
русский + английский~3,3 ГБ

Программа спросит перед загрузкой. В строке состояния будет «Загружаю…» от минуты до десяти, затем «Загрузка…», затем «Готово». Это делается один раз — дальше интернет не нужен. Через winget устанавливайте так: winget install RobertasTa.Diktuokle --interactive — иначе страница выбора языков пропускается.

Windows покажет синее окно «Windows protected your PC». У программы нет платной цифровой подписи — это не вирус. Нажмите «More info» → «Run anyway» («Подробнее» → «Выполнить в любом случае»). Контрольная сумма sha256 файла — на странице Release рядом с файлом.

Чьи это «уши»

Сердце программы — не наше. Русскую речь распознаёт GigaAM v3 — открытая модель SberDevices (лицензия MIT). Литовскую — LT_ausys: модель kmynas v4 Кристиёнаса Якубсонаса (NVIDIA Parakeet, дообученный на литовском корпусе LIEPA-3), которую мы перевели в ONNX, чтобы она работала на процессоре. Английскую — Whisper large-v3 (OpenAI). Мы собрали вокруг них окно, клавиши, обработку чисел и установщик.

До версии 0.2 русский распознавал Whisper large-v3. На тестовом наборе FLEURS он чуть точнее (3,9 % ошибок в словах против 4,6 % у GigaAM), но без видеокарты тратит около 7,2 с на предложение, а GigaAM — 0,11 с, и загружать нужно 0,23 ГБ вместо 3,1 ГБ. Большинство компьютеров видеокарты NVIDIA не имеют, поэтому выбран GigaAM. Все таблицы и как измеряли (на литовском).

Приватность — прямо

Звук и текст никогда не покидают компьютер. Интернет нужен два раза: скачать программу и при первом запуске — модели. Потом можно вытащить кабель. Журнал программа не ведёт, пока вы сами его не включите — ведь в нём был бы сам надиктованный текст, а это ваши письма, а не наше дело.

Не получается? Спросите искусственный интеллект

Не программист? В программе нажмите «?» → «Не нашли ответа? Спросите ИИ» — откроется чат с ассистентом, который уже получил инструкцию автора об этой программе: что спросить, чего нельзя утверждать, как выглядит каждая неполадка. Спрашивайте своими словами, по-русски.

Или вставьте в любой чат с ИИ: Прочитай https://raw.githubusercontent.com/RobertasTa/diktuokle/main/AI_CONSULTANT_BRIEF.md и помоги мне с Diktuokle.
